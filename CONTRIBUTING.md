# Contributing

## Data changes
- Submit domain additions or removals through the provided issue forms.
- Do not submit private, personal, or sensitive information.
- Additions must be valid domain names. Removals should include evidence that a domain is incorrectly classified.

## Code changes
1. Create a focused pull request.
2. Run `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.
3. Do not add secrets, credentials, tracking code, or undeclared network behavior.
4. Keep changes compatible with the package's offline-by-default behavior.

By contributing, you confirm that you have the right to submit the contribution under this repository's license.
